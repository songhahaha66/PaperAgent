# 回归建模技能
先判断研究目标是解释还是预测，明确响应变量、解释变量、样本单位和训练范围。只有题目需要概率或分类时才考虑相应广义线性模型。

1. 检查缺失值、单位、异常值与设计矩阵共线性；说明截距和变量编码。
2. 保留简单基线。预测任务先划分训练与测试数据，再仅在训练集拟合变换和参数；时间数据按时间划分。
3. 使用适合误差结构的回归模型，报告参数、拟合与验证指标；不能把训练拟合优度当成泛化能力。
4. 检查残差、异方差和异常影响点。诊断不满足时说明局限，不能仅靠显著性选择结论。
5. 保存代码、划分规则和真实输出；只将成功运行的参数、检验量和预测指标登记为论文证据。相关关系不自动构成因果关系。

验收提示：数据列可追溯；有基线与误差诊断；若作预测则有未参与拟合的评估数据。技能提示不能改变冻结验收协议。

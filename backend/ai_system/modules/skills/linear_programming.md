# 线性与整数规划技能
适用于目标和约束可明确线性表达的资源分配问题。先核实变量是否必须为整数或二元，不以连续松弛解冒充整数可行解。

1. 将题目成本、容量、需求和单位映射到输入参数；列明缺失参数。
2. 定义决策变量、上下界、目标方向和约束矩阵，检查量纲与不等式方向。
3. 使用可用求解器并检查状态、成功标志及不可行/无界情况，不能只读取目标值。
4. 将解代回原始约束，独立计算容量、需求、守恒和整数残差；保留真实运行输出。
5. 对关键参数作题目需要的敏感性检查，解释影子价格或松弛量的适用条件。未证明全局最优时不得声称最优。

检查建议：原约束逐项校核；整数性无遗漏；求解状态与复算一致。不得放宽冻结约束以获得可行结果。

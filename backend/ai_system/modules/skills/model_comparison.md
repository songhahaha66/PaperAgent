# 监督学习方法比较

适用于有明确预测目标、需要比较基线和候选模型的表格任务。CSV、Excel只是输入格式；先确认任务是否需要监督学习，再决定使用方法。

由当前研究Agent使用research_run_python读取数据、训练和评估；复用同一会话中的变量或保存的文件。无需创建实验、登记指标、提交结论或等待额外验收。

1. 明确目标列、特征、样本单位和预测时可用的信息。排除目标泄漏、重复样本泄漏；缺少必要字段时说明缺口。
2. 根据问题选择随机、时间或分组拆分。所有候选复用同一份划分，保存行标识、随机种子和划分规则。时间预测遵守先后顺序。
3. 保留简单基线，按研究需要选择候选数量。缺失值处理、编码、标准化和特征选择仅在训练数据上拟合；调参使用训练集内部验证，最终测试集不参与选参。
4. 保存每个候选在相同样本上的真实预测、目标值和行标识，用共同代码计算适合任务的指标。明确指标方向和比较范围；不同划分或不同目标的指标不直接排序。
5. 在线性模型中记录截距、正则项和预处理的实际设置，论文公式与实现一致。拟合失败保留具体错误，不将程序错误当作方法无效的证明。
6. 将预测表、汇总指标和必要图表保存为实际文件。回复与正文直接说明实测结果、适用条件及局限；单次拆分的误差更低不自动支持统计显著或外推有效。

这些步骤是方法指导。按任务调整计算和检查，不增加独立的研究状态机或交付门禁。

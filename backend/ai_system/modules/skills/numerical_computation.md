# 数值计算与规模检查

用 workspace_edit 把可复用逻辑保存到 code/，把单位明确的参数保存到 config/，用 research_run_file 运行入口。入口读取原始资料和参数，生成结果表与图表；修复源码后重新运行受影响的步骤。一次性短计算仍可直接 research_run_python。

1. 核对数据列、数组形状、坐标范围和采样间隔。在参数文件中写清单位；海里转米后，坐标和步长一起转换。图、表和论文沿用同一口径。
2. 分配数组前计算各维长度、元素数与 dtype.itemsize；结合运行回执中的实际内存/CPU 限额，选择网格、分块或稀疏结构。先运行小网格或少量样本，核对形状、数量级和约束，再扩大计算。
3. 分布函数优先对候选阈值向量化。存在单调关系时采用有依据的阈值搜索；保留边界、尾概率与可行性检查。不要在重复的标量分布调用上穷举庞大二维循环。
4. 优化结果用输出决策重算约束和目标；仿真记录随机种子，检查单位、初值、终值和适用的守恒关系。参数扫描复用已验证的方法，保存每种条件及实际输出。
5. 给出从原始输入运行的入口和依赖说明。执行历史供追溯，正式复现使用维护好的源码与参数，不依赖历史单元的内存变量。

这些检查在研究代码中完成，直接把实际结果和局限写入回复与正文。

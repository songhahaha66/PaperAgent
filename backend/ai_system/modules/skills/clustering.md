# 聚类分析技能
适用于无标签样本分组和探索性画像。距离、尺度和簇的形状决定方法适用性，聚类标签不是外部真值。

1. 明确样本单位和特征，处理缺失值与尺度；避免把编号等无业务含义字段当距离特征。
2. 选择与数据形状匹配的方法；使用 K-means 时记录初始化、随机种子和重复次数。
3. 对少量候选簇数比较轮廓、惯性等指标，并检查业务可解释性，不凭单张图确定结果。
4. 检查不同初始化或抽样下的稳定性，识别异常点和很小的簇；不得隐藏失败或不稳定结果。
5. 用原始指标解释各簇特征，保留分组与统计输出；登记真实运行的评价指标和画像。

验收提示：距离和预处理明确；簇数选择有依据；稳定性与解释可追溯。不把聚类分组解释为因果类别。

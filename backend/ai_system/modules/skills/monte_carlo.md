# 蒙特卡洛模拟技能
适用于输入含随机因素或需要估计不确定性的任务。随机变量分布和相关结构必须有题目、数据或明确假设依据。

1. 区分已知观测、待估参数和模拟随机变量；写明分布来源及限制。
2. 固定并记录随机数生成器与种子，保留样本量和抽样过程；避免重复使用同一随机流造成伪独立。
3. 计算目标统计量和模拟误差，逐步增加样本量观察稳定性，而不是挑选有利种子。
4. 根据统计量选择合适区间或分位数估计，必要时比较独立批次；不可把模拟误差与真实数据误差混为一谈。
5. 登记真实运行的统计量、区间和收敛检查，并在论文中明确标注模拟结果。

检查建议：分布依据明确；种子可复现；样本量与不确定性可追溯。模拟不得替代题目要求的真实数据。

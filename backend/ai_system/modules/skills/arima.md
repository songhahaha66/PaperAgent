# ARIMA 时间序列技能
适用于有明确时间顺序、等间隔观测的单变量序列。先检查缺失时间、重复时间、季节性和数据长度；短序列或结构突变需明确局限。

1. 按时间排序和划分训练/验证区间，禁止使用未来数据插值或调参。
2. 通过图形和必要的平稳性诊断决定变换及差分，避免过度差分；记录参数来源。
3. 在题目要求范围内比较少量阶数组合，至少保留朴素预测基线；季节性必须有周期依据。
4. 记录拟合收敛情况，检查残差自相关，使用滚动或保留时段验证预测误差。
5. 输出预测区间与适用期限；登记真实运行得到的误差和预测序列，不把随机示例当研究结果。

验收提示：时间切分无泄漏；模型可复现；诊断与样本外误差可追溯。数据不足时报告缺口，不伪造序列。
